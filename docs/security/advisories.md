# Security Advisories — Tyny PDF

This file tracks vulnerability advisories relevant to the Tyny PDF dependency graph.
It is updated by the scheduled `osv-scanner` job and should not be edited by hand.

## Format

Each advisory entry has:
- **package**: name of the affected dependency
- **version**: affected version range
- **advisory**: OSV/GAV identifier
- **summary**: brief description
- **severity**: critical/high/medium/low
- **fixed_in**: version containing the fix (if known)
- **detected**: ISO8601 timestamp of detection
